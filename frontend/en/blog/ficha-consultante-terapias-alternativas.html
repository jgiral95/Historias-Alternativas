How to keep a client's file in alternative therapies

What data to record, how to write up each session and how to keep your clients' files tidy in a simple, respectful way.

A client's file is your working memory: it lets you pick up each meeting without starting from zero and support the process with continuity. It doesn't need to be long, but it should be clear and consistent.

1. What to include in the first session

  • Basic details: name, ID, age, contact and support person if applicable.
  • Reason for consulting: in the client's own words, without interpreting them.
  • Context: life situation, habits, previous processes and what they expect from the support.
  • Agreements: format, frequency, fee and signed consent.

2. How to record each session

A brief, orderly note is enough. A simple structure:

  • What was worked on: technique, topic or practice of the session.
  • How the client experienced it: sensations, changes, difficulties.
  • Agreements or tasks for the next session.

Write soon, while the session is fresh, and use descriptive language instead of labels or judgments.

3. Keep things in order

  • One file per client, with a date on each entry.
  • Signed documents are not modified: if something changes, a clarifying note with its date is added.
  • Keep attachments (consents, reports) within the same file.

4. Look after confidentiality

The file contains sensitive personal information. Use strong passwords, don't share your account and avoid keeping files in loose notebooks or chats. A platform with encrypted data and access only for you reduces risks.

5. Review progress calmly

Every so often reread the client's notes: you'll see what has changed, what is still pending and when it makes sense to close or redefine the process.
